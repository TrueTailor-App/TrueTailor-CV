## 3. Deploying

`Update_site.bat` picks the newest HTML by modification date, so it will select
`TrueTailor_CV_v39_0.html` on its own. No new non-HTML files ship with this
change, so the known limitation about manual git commands does not apply here.

**One thing the .bat will not do for you:** `sw.js` caches the page. Bump its
cache name before pushing, or returning visitors keep the old version:

```js
const CACHE = 'tt-v39-0';   // was tt-v38-22 or similar
```

## 4. What to check by hand, on the live site

These are the things no test in this folder can prove. They need a real
microphone and a real API key.

1. **Record and transcribe.** Answer a gap question out loud. Confirm the
   transcript is what you said, and that nothing was added that you did not say.
   This is the one that matters most.
2. **The level meter moves while you talk.** If it stays flat, the browser is
   recording from a different input than you think.
3. **Edit the transcript.** Change a word. Confirm the red spell-check
   underlines appear under the right words, exactly as they do for typed text.
4. **Type first, then dictate.** Confirm the typed part is still there and the
   transcript was appended below it.
5. **Deny the microphone permission** once, on purpose. Confirm the message is
   readable and that typing still works.
6. **Let it run past 90 seconds.** It should stop on its own and transcribe what
   it has, not throw it away.
7. **Hebrew and Arabic layout.** Confirm the microphone button and the status bar
   sit on the correct side. I verified the strings and the `dir` attribute in
   code; I cannot see the rendered page.
8. **Safari or an iPhone**, if you have one to hand. It produces MP4/AAC rather
   than WebM/Opus, and the decode path is the same code but a different decoder.

## 5. Local testing caveat

`getUserMedia` needs a secure context. Opening the HTML from disk as
`file://...` may refuse the microphone even though everything else works.
**That is not a bug in the code.** To test locally with a real microphone:

```
cd /d "D:\Claude code\Projects\TrueTailor CV"
python -m http.server 8000
```

then open `http://localhost:8000/TrueTailor_CV_v39_0.html`.
`localhost` counts as secure; the file system does not.

## 6. Rolling back

Point `Update_site.bat` at `TrueTailor_CV_v38_22.html` (or touch that file so it
becomes the newest) and push. The version badge reads `v39.0`, so which one is
live is visible at a glance without opening the source.

Nothing in this change writes to `localStorage` except one key,
`tt_voice_deaf_v1`, which holds the list of models that refused audio and expires
after 24 hours. It is safe to delete by hand at any time and the app will simply
rediscover.
